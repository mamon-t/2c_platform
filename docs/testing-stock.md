# Тестирование «Склада» (демо по ТЗ п.15)

## Подготовка

1. Собрать плагин:
   ```sh
   cd wasm-modules/stock && cargo build --target wasm32-unknown-unknown --release
   ```
2. Приложение → **Прикладные модули** → установить `stock_plugin.wasm`
   (политики `stock.*` создадутся автоматически).
3. **Настройки → Склад** (или вкладка «Остатки» при правах settings.manage):
   кнопка «Создать метаданные склада» — создаст NOMENCLATURE,
   STOCK_LOCATION, MOVE/COUNT/HANDOVER/HANDOVER_RETURN.
4. Заполнить справочники (раздел «Документы/Каталоги»):
   - Номенклатура: `nom-paper` (type=item, category=stationery),
     `nom-monitor` (type=item, category=equipment)
   - Места учёта: `Основной склад` (warehouse), `Иванов И.` (custodian)
5. Создать документ MOVE (черновик): строки из таблицы, локации из
   выпадающих списков (reference-поля работают).

## Сценарий (шаги ТЗ п.15)

| # | Действие | Ожидание |
|---|---|---|
| 1 | Приход 10 @ 100₽ | остаток 10 |
| 2 | Приход 5 @ 120₽ | остаток 15 |
| 3 | Списание 12 | себестоимость **1240₽**, остаток 3 (партия @120) |
| 4 | Отмена документа списания (cancel_object) | сторно: остаток 15, партии восстановлены |
| 5 | Списание 100 | ошибка «Недостаточно … нужно 100, есть 15», откат |
| 6 | Перемещение 3 на второй склад | цена и дата партии уехали вместе |
| 7 | Инвентаризация, факт = 2 | недостача 1, движение count_shortage |
| 8 | Выдача монитора Иванову (HANDOVER) | остаток склада −1; **себестоимость не тронута**; появляется в «Подотчёт» |
| 9 | HANDOVER_RETURN обратно | в «Подотчёте» пусто; история: выдали→вернули |
| 10 | Просроченный возврат | красная строка во вкладке «Просрочки» |
| 11 | Журнал событий | все движения + tx-пачки видны в «Событиях» |

## Политики подписи (опционально)

```json
// signature_policies_upsert:
{
  "module": "stock",
  "action": "handover.post",
  "name": "Оборудование под подпись",
  "condition": { "nomenclature_category": "equipment" },
  "required": true
}
```

- Выдача монитора (category=equipment) без подписи → `SIGNATURE_REQUIRED`.
- Подписать: выбрать сертификат → sign_document → DER в поле
  `data.signature_der` черновика → провести.
- Выдача степлера (stationery) проходит без подписи.
