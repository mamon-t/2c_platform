# Тестирование «Торговли» (демо п.11 ТЗ)

## Подготовка

1. Собрать плагин: `cd wasm-modules/trade && cargo build --target wasm32-unknown-unknown --release`
2. Приложение → Прикладные модули → установить `trade_plugin.wasm`
3. Торговля → «Создать метаданные торговли» (settings.manage)
4. Также создать метаданные склада (StockPage) если ещё не созданы
5. Заполнить справочники:
   - Номенклатура: товар «Бумага А4» (category=stationery)
   - Место учёта: «Основной склад» (warehouse)
   - Контрагенты: поставщик (supplier), покупатель (customer)
   - Тип цен + цены (опционально)

## Дизайн-решение: себестоимость — проекция движений

Себестоимость реализаций **не хранится в строках документа**. Она читается
из движений склада (`stock_movements`) по индексу `(company_id, doc_id, line_ref)`:

- при проведении SALES каждая строка передаёт `line_ref` (= `data.lines[].line_id`,
  фолбэк `l{индекс}`) в операцию `stock.issue`; FIFO пишет движение на каждую
  съеденную партию с точным `unit_cost`;
- проводка COGS строится из результата складской операции через `$ref`
  (`{"$ref": "op_id.total_cost"}`) — одна цифра на склад и бухгалтерию;
- чтение: host-fn `stock_doc_cost(doc_id)` / IPC `stock_doc_cost` — группировка
  по `(line_ref, nomenclature)`; отменённые движения исключаются фильтрами
  `is_reversal / reversed`, поэтому при отмене документа себестоимость «исчезает» сама;
- возврат от покупателя берёт среднюю по строке исходной реализации:
  `Σcost_строки / Σqty_строки × возвращаемое_qty` (по `source_sales_id`);
  object.patch для записи стоимости в строки не нужен и не планируется.
